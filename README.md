# Угадай спину — игра «Шпион» на одном смартфоне

Веб-приложение для классической компанейской игры **«Шпион» (Spy Game)** с передачей одного телефона между участниками в дизайне **Google Material You (Material 3)**. Полностью статический проект на базе React + TypeScript + Vite + Tailwind CSS, готовый к публикации на **GitHub Pages** через **GitHub Actions**.

## Механика игры
1. **Выбор участников:** от 3 до 5 персонажей (Расул — белый, Салих — жёлтый, Микаил — фиолетовый, Денислам — красный, Изамутдин — зелёный) с локальными фотографиями профиля в **IndexedDB**.
2. **Тайная раздача ролей:** в каждом раунде случайно выбирается ровно один шпион. Все обычные участники получают одно общее секретное слово, а шпион видит надпись «Ты шпион».
3. **Обсуждение (3 минуты):** игроки задают друг другу вопросы, стараясь вычислить шпиона и не выдать секретное слово.
4. **Тайное голосование:** по истечении таймера (или досрочно) каждый участник по очереди тайно голосует против главного подозреваемого.
5. **Раскрытие и очки:** раскрывается настоящий шпион и секретное слово, определяется победитель и начисляются очки, которые сохраняются между раундами.
6. **Таблица лидеров и звания:** в конце сессии формируется итоговый рейтинг игроков с очками и уникальными званиями.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка статического сайта в папку `dist/`:

```bash
npm run build
```

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "Spy Game: Угадай спину"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin main
   ```
2. Откройте вкладку **Settings → Pages** в репозитории GitHub.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. Workflow `Deploy to GitHub Pages` соберёт и опубликует приложение автоматически.
